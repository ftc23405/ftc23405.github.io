# Sponsor logos

Drop the logo files here with these exact filenames and the site picks them up automatically:

| File | Sponsor |
|---|---|
| `polymaker.png` | Polymaker |
| `numurus.png` | Numurus |
| `digitech-labs.png` | Digitech Labs |
| `microsoft.png` | Microsoft |

Guidelines:
- **Format:** PNG with a transparent background (SVG also works — change the `src` in `index.html` to `.svg`).
- **Size:** roughly 600&times;200 px, logo centered with a little padding.
- **Height:** the site caps rendered height at 56 px, so wide horizontal lockups look best.

If a file is missing, the site falls back to the sponsor's name in text — nothing breaks, it
just looks less polished.
